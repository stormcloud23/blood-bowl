# Player portrait intake

Drop one original photo per player position into its team folder. Use the filename stem in that folder’s checklist and keep the original extension (.jpg, .jpeg, .png, or .webp).

Use the highest-resolution photo you have, ideally with the face and shoulders clearly visible. Leave cropping for the batch pass. Either facing direction is fine.

The Imperial Nobility folder includes the example `ogre.jpg`. Shared position names are scoped to each team folder. Put each Star Player in the Star Players folder once, regardless of team eligibility.
