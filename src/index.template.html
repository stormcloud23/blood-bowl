Pitch markers

White outline: selected player or destination. Numbered squares: planned route. Gold squares: push destinations. Gold target with an AV badge: foul target. Red outline: push target. Bright players: eligible reaction targets; faded players: unavailable. Dashed token: prone. Red token border: stunned. Purple token border: distracted. Brown/black squares: trapdoors.

Passing & throwing

Colors use the same 2+ to 6+ scale as movement; × means automatic failure. Pass labels show pass/catch rolls; the color shows the pass roll. Red enemy squares show interception rolls for an accurate pass. Throw Team-mate colors show Superb Throw difficulty.
